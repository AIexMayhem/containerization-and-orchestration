# Техническое задание

Документ: technical-spec. Версия: v1. Пакет: demo-tender/v1.
Синтетический документ для учебного эксперимента.

## TS-1. Предмет работ

Исполнитель обеспечивает сопровождение внутреннего веб-приложения заказчика: приём обращений, диагностику неисправностей и восстановление работоспособности.

## TS-2. Режим поддержки

Приём и обработка обращений инженерами поддержки должны быть доступны круглосуточно, семь дней в неделю, включая праздничные дни: 24×7.
